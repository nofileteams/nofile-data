はい。PyQt5 → PyQt6 では、特に Qt の enum 周りが大きく変わっています。
提示された import 構成なら、まず以下を押さえると移植しやすいです。
1. setWindowFlags() / setWindowFlag() が大きく変わる
PyQt5
self.setWindowFlags(
    Qt.FramelessWindowHint |
    Qt.WindowStaysOnTopHint |
    Qt.Tool
)

PyQt6
self.setWindowFlags(
    Qt.WindowType.FramelessWindowHint |
    Qt.WindowType.WindowStaysOnTopHint |
    Qt.WindowType.Tool
)

PyQt6では、多くの enum が階層化されています。
PyQt5	PyQt6
Qt.FramelessWindowHint	Qt.WindowType.FramelessWindowHint
Qt.WindowStaysOnTopHint	Qt.WindowType.WindowStaysOnTopHint
Qt.Tool	Qt.WindowType.Tool
Qt.Dialog	Qt.WindowType.Dialog
Qt.Window	Qt.WindowType.Window
Qt.CustomizeWindowHint	Qt.WindowType.CustomizeWindowHint
Qt.WindowCloseButtonHint	Qt.WindowType.WindowCloseButtonHint
Qt.WindowMinimizeButtonHint	Qt.WindowType.WindowMinimizeButtonHint
Qt.WindowMaximizeButtonHint	Qt.WindowType.WindowMaximizeButtonHint

つまり、
Qt.XXX

だったものが、
Qt.XXXType.XXX

のようになるケースがかなりあります。

7. QPixmap / QIcon
基本的な使い方はかなり同じです。
PyQt5

pixmap = QPixmap("image.png")

PyQt6
icon = QIcon("icon.png")
pixmap = QPixmap("image.png")

ここは基本的に変更ありません。
8. QUrl
これも基本的には同じです。
PyQt5 / PyQt6
url = QUrl("https://example.com")

WebEngineなら、
self.browser.setUrl(QUrl("https://example.com"))

のままでOKです。
9. QTimer
基本的にはほぼ同じです。
timer = QTimer(self)
timer.timeout.connect(self.update)
timer.start(1000)

PyQt5 → PyQt6で大きな変更はありません。
10. QApplication
基本的には同じです。
app = QApplication(sys.argv)
window = QMainWindow()
window.show()
sys.exit(app.exec())

ただし、ここは重要です。
PyQt5
sys.exit(app.exec_())

PyQt6
sys.exit(app.exec())

PyQt6では exec_() ではなく exec() です。

17. QMouseEvent の位置取得
ここもPyQt6移植時に遭遇しやすいです。
PyQt5では、

event.pos()

を使っていたコードが、PyQt6では
event.position()

になっています。
例えば：

PyQt5
pos = event.pos()
x = pos.x()
y = pos.y()

PyQt6
pos = event.position()
x = pos.x()
y = pos.y()

ただし position() は QPointF なので、整数が必要なら、
pos = event.position().toPoint()

とすることがあります。

PyQt6でも基本的に：
event.angleDelta()

なので、この辺はそのままです。

22. Qt の enum は「カテゴリ化」されたと考えると分かりやすい
PyQt5では大量のものが直接 Qt にぶら下がっていました。
Qt.LeftButton
Qt.AlignCenter
Qt.Key_Escape
Qt.FramelessWindowHint
Qt.ScrollBarAlwaysOff
Qt.Horizontal
Qt.Vertical

PyQt6ではカテゴリーごとに分けられています。
Qt.MouseButton.LeftButton
Qt.AlignmentFlag.AlignCenter
Qt.Key.Key_Escape
Qt.WindowType.FramelessWindowHint
Qt.ScrollBarPolicy.ScrollBarAlwaysOff
Qt.Orientation.Horizontal
Qt.Orientation.Vertical

これがPyQt5 → PyQt6移植で一番重要な変更です。
23. 今回のimportなら、特に注意するもの
あなたのコード：
from PyQt5.QtCore import Qt, QUrl, QTimer
from PyQt5.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QTextEdit,
    QPushButton, QFrame, QVBoxLayout, QMainWindow, QScrollArea
)
from PyQt5.QtWebEngineWidgets import QWebEngineView
from PyQt5.QtGui import QIcon, QPixmap

をPyQt6にすると、import自体は基本的に：
from PyQt6.QtCore import Qt, QUrl, QTimer
from PyQt6.QtWidgets import (
    QApplication,
    QWidget,
    QLabel,
    QLineEdit,
    QTextEdit,
    QPushButton,
    QFrame,
    QVBoxLayout,
    QMainWindow,
    QScrollArea,
)
from PyQt6.QtWebEngineWidgets import QWebEngineView
from PyQt6.QtGui import QIcon, QPixmap

です。
import名が変わるというより、importした後の enum の指定方法が変わるケースが多いです。
